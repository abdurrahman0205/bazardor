## About the Project

Bazardor is a market price tracking website that helps users stay informed about the daily prices of essential products across different market categories. It allows users to explore current market prices, track price increases and decreases compared to the previous day, and identify products with the highest and lowest prices. Users can also log in to access detailed product information.

---

## Project Overview

- Explore products across different market categories.
- Check today's market prices.
- Compare today's prices with yesterday's to see whether prices have increased or decreased.
- Identify products with rising and falling prices.
- View the highest and lowest prices of products.
- Log in to access detailed product information.

---

## Key Features

- **Daily Market Prices** — Explore the latest available prices of products across different market categories.
- **Price Change Tracking** — See how product prices have increased or decreased compared to the previous day.
- **Top Risers and Fallers** — Identify products with the largest price increases and decreases.
- **Highest and Lowest Prices** — View the highest and lowest recorded prices for products.
- **Product Details** — Log in to access detailed information about individual products.
- **User Authentication** — User authentication powered by Better Auth.
- **Bengali Price Formatting** — Display market prices and relevant units in Bengali format.
- **Responsive Interface** — Browse the website across different screen sizes.

## Installation & Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/abdurrahman0205/bazardor.git
   ```

2. Navigate to the project folder:

   ```bash
   cd bazardor
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Configure the required environment variables in a `.env.local` file in the project root. Refer to the project's configuration and authentication setup for the required values.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open [http://localhost:3000](http://localhost:3000) in your browser.
